# S05-M04 资源类型字典 — 需求规格
## 子模块信息
| 项目 | 内容 |
|------|------|
| 所属系统 | S05 草稿编辑服务（VectCutAPI） |
| 子模块编号 | S05-M04 |
| 功能点范围 | S05-014 ~ S05-026 |
| 功能点数 | 13（12 个资源列表端点 + 1 个配置功能点） |
| 涉及业务对象 | BO-05-013 资源类型条目、BO-05-014 编辑服务配置 |
| 涉及角色 | R02 外部 AI Agent、R03 脚本/程序调用方、R04 系统运维/开发者（S05-026） |
## 共用原型说明（S05-014 ~ S05-025）
S05-014~025 为 12 个同构的只读 GET 资源列表端点，共用一个用例模式（下称"字典查询原型"）；每个端点仍为独立功能点，各自拥有独立出参清单与专属校验规则。原型共性：

- **用途**：编辑类端点（M02/M03）的取值参数（动画/转场/蒙版/字体/特效）必须先经字典查询获得合法取值，再作为参数传入 add_* 端点；字典是"参数合法性的唯一来源"。
- **共用 BO-05-013 资源类型条目**（数据字典见下，全部端点复用，仅 category 取值不同）：

| 编码 | 业务对象 | 数据项 | 数据类型 | 长度 | 必填 | 编码引用说明 | 备注 |
|------|---------|--------|---------|------|------|------------|------|
| BO-05-013 | 资源类型条目 | category | VARCHAR | 50 | Y | 本子模块各端点专属类别 | 如 intro_animation/transition |
| BO-05-013 | 资源类型条目 | type_code | VARCHAR | 50 | Y | 供 add_* 端点引用的类型编码 | 作为入参取值 |
| BO-05-013 | 资源类型条目 | type_name | VARCHAR | 100 | Y | 类型中文名/展示名 | 供 UI 与对话展示 |
| BO-05-013 | 资源类型条目 | applicable_object | VARCHAR | 50 | Y | 适用对象（视频/图片/文字/音频） | 限定可用端点 |
| BO-05-013 | 资源类型条目 | extra_params | TEXT(JSON) | - | N | 该类型的可调参数定义 | 如时长/强度 |
| BO-05-013 | 资源类型条目 | is_preset | JSON bool | 1 | Y | 是否内置预设 | 全部 true（本地包内置） |

- **共用用例模式**（各端点用例在此骨架上替换类别与专属规则）：
  1. GET 请求无入参（无鉴权、无副作用）；
  2. 响应为统一 JSON 包：{code, msg, data:[BO-05-013 条目数组]}；
  3. 列表内容只读，端点不提供新增/修改/删除；
  4. 条目来源为 pyJianYingDraft 本地包内置枚举，服务重启后内容稳定；
  5. applicable_object 与目标 add_* 端点匹配性由调用方负责，add_* 端点侧再校验。
- **共用处理逻辑**：读取本地包枚举 → 按 category 组装条目 → 返回统一 JSON 包。
- **共用接口依赖**：输出→M02/M03 编辑端点（取值校验来源）；输出→S08-004 get_animations 工具（category 参数路由）；内部→pyJianYingDraft 枚举读取。
- **共用角色权限**：全部操作 R02 外部 AI Agent、R03 脚本/程序调用方（R01 经 S04 对话间接获得字典提示）。

## S05-014 入场动画列表 get_intro_animation_types
### 一、功能综述
返回视频/图片片段可用的入场动画类型字典，供 add_video 的出入场修饰与 add_image 的 intro_animation 参数取值。示例条目：渐显、向右滑入、放大进入（以运行时字典为准）。
### 二、业务对象与出参清单
共用 BO-05-013，category=intro_animation。出参清单：| 字段 | 说明 |：| category | 固定 intro_animation |；| type_code | 入场动画编码 |；| type_name | 动画展示名 |；| applicable_object | video/image |；| extra_params | 动画时长等 |；| is_preset | true |。
### 三、业务活动
读取枚举并组装入场动画条目；只读返回。
### 四、用例描述
##### 用例 U-05-014-01 查询入场动画字典
| 项目 | 内容 |
|------|------|
| 用例编号 | U-05-014-01 |
| 用例名称 | 获取可用入场动画列表 |
| 业务说明 | 编辑前查询合法入场动画取值，供选择后传入 add_video/add_image |
| 规范引用 | 无（本地只读字典，无外部合规约束） |
| 业务规则 | 1. 无入参，任何 GET 调用均返回同一稳定列表；<br>2. 响应条目必须包含 type_code 与 type_name，缺一视为响应不合法；<br>3. applicable_object 须标明 video/image 适用范围；<br>4. 端点只读，不得引入写副作用 |
| 使用范围 | R02 外部 AI Agent、R03 脚本/程序调用方 |
| 先决条件 | 服务已启动 |
**功能要求：** 基本功能 1 个：返回 category=intro_animation 的全部条目。辅助功能：无。提示信息：无。
**处理逻辑：** 按共用处理逻辑执行。
**约束条件：** 列表规模随本地包版本变化，调用方不得硬编码缓存跨版本使用。
**信息处理要求：** 输入：无；输出：BO-05-013 条目数组（category=intro_animation）。
**业务表单：** 无。
**角色权限：**
| 功能点 | 使用人员 |
|--------|---------|
| S05-014 全部操作 | R02 外部 AI Agent、R03 脚本/程序调用方 |
### 五、接口依赖

| 输出 | S05-M02 | add_video/add_image 入场动画取值来源 | 进程内/REST JSON |
