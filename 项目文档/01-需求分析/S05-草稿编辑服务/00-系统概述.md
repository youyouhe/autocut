## 一、系统概述

### 1.1 系统定位

草稿编辑服务（VectCutAPI）是 AI 视频工作台内容生产链路的"编辑中枢"，位于素材感知（S01/S02）与内容组装（S03/S04）之后、无人值守渲染（S06）之前。其实体为 VectCutAPI/capcut_server.py（基于本地 Python 包 pyJianYingDraft），以 28 个 REST 端点提供程序化草稿编辑能力，被核心服务 render_server 融合挂载在统一端口 9002 下（融合机制见 S07-001）。

系统将"剪映工程草稿"抽象为可编程对象：上层调用方（对话式生产 S04 的 function calling 工具链、MCP 工具服务 S08、模板引擎 S03 的组装流程、外部脚本 R03）通过本系统创建草稿、向时间线添加视频/音频/图片/文字/字幕/贴纸/特效/关键帧，再交由 S06 注入剪映并真后台渲染，从而实现"无人手工剪辑"的自动化生产线。

### 1.2 业务范围

1. **草稿生命周期管理**（M01）：创建草稿、保存到磁盘、查询草稿脚本/状态、生成草稿 URL；
2. **素材轨道添加**（M02）：向草稿时间线添加视频轨道（含转场/蒙版/变速/音量）、音频轨道、图片、文字（含字体/颜色/阴影/背景/动画）、批量字幕、贴纸；
3. **效果与关键帧**（M03）：添加特效（场景特效/人物特效）、为视频片段添加关键帧（属性随时间变化）；
4. **资源类型字典**（M04）：提供 12 个资源类型列表查询端点（入场/出场/组合动画、转场、蒙版、音效、字体、文字三类动画、视频场景/人物特效），供调用方在编辑前获取合法取值；以及草稿格式配置（draft_profile 三档位、IS_CAPCUT_ENV、PORT）。

### 1.3 用户角色（引用 _metadata.md 角色定义）

| 角色编码 | 角色名称 | 在本系统中的用法 |
|---------|---------|----------------|
| R02 | 外部 AI Agent | 经 S08 MCP 工具服务（create_draft/add_video/add_text/add_audio/save_draft、get_animations）间接调用本系统端点，完成自动化编辑 |
| R03 | 脚本/程序调用方 | 通过 curl/HTTP 直接调用 28 个 REST 端点（如 zip 直传渲染前的草稿组装流水线、模板引擎执行流程） |
| R04 | 系统运维/开发者 | 维护 VectCutAPI/config.json（draft_profile/IS_CAPCUT_ENV/PORT）、处理兼容性告警与依赖安装（oss2/json5/pyJianYingDraft 本地包） |
| R01 | 视频创作者 | 经 S04 对话面板的编辑工具链（S04-003）间接触发本系统能力，非直接调用方 |

### 1.4 系统边界

| 边界项 | 说明 |
|--------|------|
| 覆盖范围 | 28 个编辑端点的会话内草稿操作、草稿文件落盘（draft_content.json/draft_meta_info.json）、资源类型枚举查询、编辑服务自身配置 |
| 不覆盖 | 草稿注入剪映与渲染执行（S06-006/S06-008）、剪映草稿目录的列表/封面/删除管理（S07-008 /api/drafts）、对话编排（S04）、模板解析（S03）、感知分析（S02） |
| 上游输入 | 素材文件路径（来自 S01 render_uploads/ 或本地磁盘）、资源取值字典（本系统 M04 自查） |
| 下游输出 | 草稿文件夹（可被 S06-002 /render/draft/<draft_id> 消费）、草稿脚本 JSON（供 S04 对话上下文与质检回溯） |
| 外部依赖 | EXT-01 剪映专业版 5.9.0（草稿格式的最终消费者，格式须兼容）、EXT-06 MCP 客户端（经 S08 间接接入）；pyJianYingDraft 为本地内嵌包（VectCutAPI/pyJianYingDraft/），不作外部系统 |
