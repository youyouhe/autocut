## S05-012 添加特效 add_effect

### 一、功能综述

添加特效将剪映风格的画面特效（氛围/纹理等场景类特效、人物修饰类特效）应用到草稿的目标区间。特效取值必须来自资源字典：视频场景特效（S05-024 列表）与视频人物特效（S05-025 列表）。特效片段独立于素材片段存在，可作用于整轨或指定区间，是实现"一键氛围感"的自动化入口——S04 对话中的"加个复古滤镜"类指令与 S03 模板中的 effect 声明最终均落至本端点。

### 二、业务对象

| 编码 | 业务对象 | 数据项 | 数据类型 | 长度 | 必填 | 编码引用说明 | 备注 |
|------|---------|--------|---------|------|------|------------|------|
| BO-05-011 | 特效片段 | draft_id | VARCHAR(UUID) | 36 | Y | 引用 BO-05-001 | 目标草稿 |
| BO-05-011 | 特效片段 | effect_id | VARCHAR | 50 | Y | 取值引用 S05-024/S05-025 | 特效类型编码 |
| BO-05-011 | 特效片段 | effect_name | VARCHAR | 100 | Y（出参） | 字典回显名称 | 便于调用方核对 |
| BO-05-011 | 特效片段 | apply_target | VARCHAR | 20 | Y | video_track / segment | 作用对象（整轨或片段） |
| BO-05-011 | 特效片段 | target_start | DECIMAL | (10,3) | Y | 生效起点（秒） | — |
| BO-05-011 | 特效片段 | target_end | DECIMAL | (10,3) | Y | 生效终点（秒） | 大于 start |
| BO-05-011 | 特效片段 | params | TEXT(JSON) | - | N | 特效强度等可调参数 | 按特效类型定义 |

### 三、业务活动

校验特效取值合法性（对照 M04 字典）；按作用对象与区间写入特效轨/片段属性；返回特效名称；刷新时间线。

### 四、用例描述

##### 用例 U-05-012-01 为视频区间添加特效

| 项目 | 内容 |
|------|------|
| 用例编号 | U-05-012-01 |
| 用例名称 | 添加场景/人物特效 |
| 业务说明 | 为整条视频轨或选定区间叠加氛围/人物特效（如复古、降噪磨皮类） |
| 规范引用 | _metadata.md 数据类型约定（长文本 TEXT(JSON)、时间区间 DECIMAL(10,3)） |
| 业务规则 | 1. effect_id 必须存在于 S05-024（视频场景特效）或 S05-025（视频人物特效）列表，非法值返回错误并回显可用取值；<br>2. apply_target 只允许 video_track/segment 两个取值，segment 时须能定位到既有片段；<br>3. target_end 大于 target_start；生效区间超出时间线总时长时按时间线截断并提示；<br>4. params 中的可调参数按特效类型校验（数值范围），未声明的参数名忽略且不报错 |
| 使用范围 | R02 外部 AI Agent、R03 脚本/程序调用方（R01 经 S04-003 间接使用） |
| 先决条件 | S05-001 已创建草稿；时间线上已存在视频片段 |

**功能要求：**

| 类型 | 描述 |
|------|------|
| 基本功能 | 共计 3 个基本功能点：|
| | 1. 校验并写入合法特效到目标区间 |
| | 2. 支持整轨/片段两种作用对象 |
| | 3. 应用特效可调参数并回显特效名称 |
| 辅助功能 | 非法取值时返回可用取值列表 |
| 提示信息 | 区间截断、片段不存在提示 |

**处理逻辑：**
1. 校验 draft_id、effect_id（对照 S05-024/S05-025 字典）、apply_target 与区间；
2. 按 apply_target 定位轨道或片段；
3. pyJianYingDraft 写入特效及 params，返回 effect_name。

**约束条件：**
1. 同一区间叠加多个同类特效的渲染顺序由剪映决定；
2. 特效渲染耗时随区间增长，建议控制作用区间。

**信息处理要求：**

|------|------|
| 输入信息 | JSON：BO-05-011 全部入参字段 |
| 输出信息 | JSON：{effect_name, 实际生效区间}（BO-05-011） |

**业务表单：** 无。

| 功能点 | 使用人员 |

## S05-013 视频关键帧 add_video_keyframe

### 一、功能综述

视频关键帧为视频片段的某个可动画属性（如缩放、位置、不透明度）在指定时刻设定关键值，使属性随时间在关键帧之间插值变化，实现推拉镜头（Ken Burns）、淡入淡出等动态效果。本端点是"静态素材动态化"的支撑能力：S03 模板的图片运镜、S04 对话的"镜头慢慢推近"指令均通过关键帧序列表达。关键帧隶属于既有视频片段，须先有 add_video/add_image 片段再打关键帧。

### 二、业务对象

| 编码 | 业务对象 | 数据项 | 数据类型 | 长度 | 必填 | 编码引用说明 | 备注 |
|------|---------|--------|---------|------|------|------------|------|
| BO-05-012 | 视频关键帧 | draft_id | VARCHAR(UUID) | 36 | Y | 引用 BO-05-001 | 目标草稿 |
| BO-05-012 | 视频关键帧 | segment_id | VARCHAR | 50 | Y | 引用 BO-05-005/BO-05-007 片段 | 目标视频/图片片段 |
| BO-05-012 | 视频关键帧 | keyframe_property | VARCHAR | 30 | Y | scale/position/alpha 等 | 可动画属性枚举 |
| BO-05-012 | 视频关键帧 | keyframe_time | DECIMAL | (10,3) | Y | 片段内时刻（秒） | 0 ≤ time ≤ 片段时长 |
| BO-05-012 | 视频关键帧 | keyframe_value | TEXT(JSON) | - | Y | 属性值（数值或坐标对） | 类型随属性 |

### 三、业务活动

定位目标片段；校验属性与时刻；写入关键帧；多关键帧按时刻排序参与插值。

### 四、用例描述

##### 用例 U-05-013-01 为片段设置属性关键帧

| 项目 | 内容 |
|------|------|
| 用例编号 | U-05-013-01 |
| 用例名称 | 添加视频关键帧 |
| 业务说明 | 为图片/视频片段的缩放属性在首尾各打一个关键帧，实现缓慢推近运镜 |
| 规范引用 | _metadata.md 数据类型约定（时间 DECIMAL(10,3)、JSON bool/TEXT） |
| 业务规则 | 1. segment_id 必须指向草稿内既有视频/图片片段，不存在返回错误；<br>2. keyframe_time 须落在 [0, 片段时长] 区间内，越界拒绝；<br>3. 同一片段同一属性同一时刻重复打帧按覆盖处理（幂等），不产生重复帧；<br>4. keyframe_value 须与属性类型匹配（scale/alpha 为数值，position 为坐标对），类型不符拒绝并说明期望类型 |
| 使用范围 | R02 外部 AI Agent、R03 脚本/程序调用方（R01 经 S04-003 间接使用） |
| 先决条件 | 草稿内已存在目标片段（S05-006/S05-008 已执行） |

**功能要求：**

| 类型 | 描述 |
|------|------|
| 基本功能 | 共计 3 个基本功能点：|
| | 1. 为指定片段属性在指定时刻写入关键帧 |
| | 2. 支持数值与坐标两类属性值 |
| | 3. 同刻同属性覆盖（幂等） |
| 辅助功能 | 单属性至少两帧即可成动画的校验提示 |
| 提示信息 | 片段不存在/时刻越界/类型不符提示 |

**处理逻辑：**
1. 校验 draft_id、segment_id、属性枚举与时刻区间；
2. 按属性校验 value 类型；
3. pyJianYingDraft 写入关键帧并按时刻排序，返回关键帧标识。

**约束条件：**
1. 关键帧密度过高（毫秒级连续打帧）渲染插值开销大，建议合理间隔；
2. 关键帧不可独立渲染，随所属片段生效。

**信息处理要求：**

| 方向 | 内容 |
|------|------|
| 输入信息 | JSON：BO-05-012 全部入参字段 |
| 输出信息 | JSON：{keyframe_id, keyframe_time}（BO-05-012） |

**业务表单：** 无。

**角色权限：**

| 功能点 | 使用人员 |
|--------|---------|
| S05-013 全部操作 | R02 外部 AI Agent、R03 脚本/程序调用方 |

### 五、接口依赖
