## 一、系统概述

### 1.1 系统定位

S06 无人值守渲染是全系统的技术核心，解决"剪映专业版 5.9.0 无开放 API"前提下批量
产出成片的问题。剪映导出接口 `videoeditor.dll!ExportClient::exportStart` 仅能导出
当前已加载草稿且请求结构不含草稿路径，草稿加载逻辑位于 VMProtect 保护的
VECreator.dll，API 直驱任意草稿被架构阻断（手册 §20.1），因此本系统采用
**Frida 注入 + Win32 多桌面 + 合成鼠标键盘事件** 的 UI 自动化路线，驱动剪映完成
"注入草稿 → 打开编辑器 → 导出 → 完成检测 → 清理" 全闭环，期间用户主桌面无感。

### 1.2 业务范围

1. 渲染任务接入：zip 直传渲染（/render）与按草稿 ID 渲染（/render/draft/<id>）两种提交方式；
2. 任务调度：queued/rendering/done/error 四态生命周期 + 双桌面渲染池互斥排队；
3. 渲染驱动闭环：草稿注入、真后台桌面隔离、导出闭环（含重试）、完成检测、草稿清理；
4. 底层注入能力：Frida 合成事件 RPC 层、modal 检测与窗口跟踪、渲染监视器；
5. 运维支撑：8 坐标校准（calib.json）、渲染状态/下载/列表 API。

### 1.3 用户角色（引用 _metadata.md 角色子集）

| 角色编码 | 角色名称 | 在本系统中的职责 |
|---------|---------|----------------|

| R02 | 外部 AI Agent | 经 MCP render/render_status 工具触发渲染并跟踪 |
| R03 | 脚本/程序调用方 | curl/HTTP 直接调用 /render 系列 REST（zip 直传流水线） |
| R04 | 系统运维/开发者 | 坐标校准、多桌面/ Frida 注入故障排查、监视器观察 |

## 四、接口汇总（全系统 12 个接口）

| 接口编号 | 方向 | 对接系统/消费方 | 接口说明 | 数据格式 |
|---------|------|---------------|---------|---------|
| IF-06-01 | 输入 | R01/R03 → 本系统 | POST /render：zip 直传异步渲染 | multipart（draft=zip + draft_name 可选），返回 JSON {task_id, poll} |
| IF-06-02 | 输入 | R01/R02/R03 → 本系统 | POST /render/draft/&lt;draft_id&gt;：按 S05 草稿 ID 渲染 | REST 路径参数 UUID36，返回 JSON {task_id, poll} |

| IF-06-04 | 输出 | 本系统 → R01/R03 | GET /render/download/&lt;task_id&gt;：下载成片 | 二进制 mp4 流（仅 done 后） |
| IF-06-05 | 输出 | 本系统 → R01/R03 | GET /render/list：任务列表 | JSON 数组 |
| IF-06-06 | 内部 | M01 → M02 | render_driver.py render-draft 子进程（--desktop --desktop-name --close） | 命令行参数 + 退出码 / stdout |

| IF-06-08 | 输出 | 本系统 → EXT-01（Win32） | CreateDesktopW/OpenDesktopW + CreateProcessW(lpDesktop) + STARTF_USESIZE 1280×720 启动剪映 | Win32 API 调用 |
| IF-06-09 | 内部 | M02 → M03 | Frida attach 剪映进程（跨桌面 by PID）+ hook_focus.js rpc.exports 8 个 RPC | Frida RPC（JS） |
| IF-06-10 | 内部 | M02 ↔ calib.json | 校准坐标读写（card/export/confirm/close_done/close_editor/search_btn/search_box/result_card） | JSON 文件 |
| IF-06-11 | 输入 | EXT-01 → 本系统 | 渲染输出轮询：C:\Users\Administrator\Videos\&lt;draft_name&gt;*.mp4 文件探测 | 文件系统 |
| IF-06-12 | 内部 | M03 → R04 | render_monitor.py 后台进程 + render_monitor.log 状态机日志 | 进程 + 日志文件 |
